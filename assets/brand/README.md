# HandyBar icon

The approved mark combines a rounded H with a floating menu bar.

- [handybar-icon.svg](handybar-icon.svg): editable vector master for light backgrounds.
- [handybar-icon-white.svg](handybar-icon-white.svg): the same geometry for dark backgrounds.
- [handybar-icon.png](handybar-icon.png): approved ImageGen raster original, 1254 × 1254, with transparency.

The SVG redraw preserves the original silhouette and spacing while regularizing
the curves and using a solid fill. It contains a path and rounded rectangle, with
no embedded bitmap, fonts, or external dependencies. Keep the geometry of both
SVG variants in sync when editing.

These are brand assets, not a macOS app icon set or a tested menu-bar template
image. Prepare and validate the platform-specific sizes when implementing the app.
