# Security policy

## Supported versions

HandyBar is in the planning stage and has no supported releases yet.
Report concerns in the current source or planned behavior using a private channel.

## Reporting a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/maytad/HandyBar/security/advisories/new)
or the repository's Security tab to report a
vulnerability privately. Include the affected version or commit, reproduction
steps, expected impact, and a minimal example with sensitive information removed.

If the reporting form is unavailable, request that the maintainer enable a
private reporting channel without disclosing vulnerability details. Keep exploit
details, credentials, and personal data out of public issues and pull requests.

Coordinate disclosure with the maintainer through the private report. The project
does not currently promise a fixed response time or a bug bounty.

## Maintainer setup

Keep private vulnerability reporting enabled using
[GitHub's setup instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
Verify the reporting channel after changing repository settings. Keep supported
versions and reporting instructions current as releases become available.
