# HandyBar

HandyBar is a macOS menu bar utility for alarms, repeated mouse clicks, and disk cleanup.

## Language

**Alarm**:
A user-set time of day at which HandyBar rings, either once or on chosen weekdays. A user can keep several Alarms, each switched on or off.
_Avoid_: Timer, countdown, reminder

**Repeat days**:
The weekdays on which an Alarm rings again; an Alarm with no repeat days rings once.

**Ringing**:
An Alarm whose time has arrived while the Mac is awake: HandyBar shows it above other windows and plays its sound (one of HandyBar's built-in sounds, chosen per Alarm) until the user stops it.

**Missed Alarm**:
An Alarm whose time passed while the Mac was asleep or HandyBar was not running. It never rings late; HandyBar shows that it was missed.
_Avoid_: Skipped alarm, late alarm

**Auto Click**:
Repeated mouse clicks performed automatically under the user's control.

**Cleanup**:
A user-initiated disk-space cleanup performed through Mole CLI.
